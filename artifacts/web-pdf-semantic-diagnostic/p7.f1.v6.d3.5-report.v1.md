## Cost evidence
- Worst attempt at the envelope cap (147,456 bytes, top tier applied to the byte count): 0.04096 USD.
- Six attempts: 0.24576 USD. Ceiling 0.30 USD.
- Each attempt's reserve is checked before sending; a fourth-tier body near 1,000,000 bytes is refused before its second send (tested).
- The reserve is a worst case under stated assumptions: tokens bounded by bytes, completion 65,536, route tier by byte count. Reasoning tokens and the endpoint's token accounting are NOT verified. The figure is not the billed amount.
