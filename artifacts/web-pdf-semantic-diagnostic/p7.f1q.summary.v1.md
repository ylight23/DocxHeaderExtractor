### Tool chain evidence (acceptance criterion of the Issue #5 update)

V1: tools were declared to the model (+1,063 prompt tokens per request vs. the no-tool arm), but in
10/10 requests Qwen answered directly; its reasoning never mentions tools. V1 therefore proves the
declaration path only.

V2 (`F1QToolsMandatory`, separately frozen; Alibaba does not support `tool_choice=required`, so the
requirement is in the question and checked by the harness): 9/10 requests show the full chain
**Qwen `tool_calls` → C# evidence tool → real source evidence → Qwen final F1**. Canary
`requests/D05-PACK_001.F1QToolsMandatory/`: turn 1 `finish_reason=tool_calls` with 6 calls
(`get_source_span` O1–O5/O39/O45/O46; `get_occurrence_context` O5, O39, O45, O46, O47), 6
`role:tool` replies with matching `tool_call_id`s whose content carries the source sha
`f427233d…2318` and the evidence-store sha; turn 2 `finish_reason=stop`, contract-valid. A published-raw
test re-verifies this transcript and every manifest hash. SRC-089 was the 1/10 that still answered
without tools (`TOOL_EVIDENCE_REQUIRED_NOT_REQUESTED`). Only 13 decisions cite an evidenceId
(`E#.#`); most cite source aliases even when tool evidence was retrieved.

## Verdict

- Tool library, tool-calling route and the end-to-end chain work on real provider calls and real source
  evidence (V2, 9/10). When tools are optional, Qwen does not request evidence (V1, 0/10).
- The independent question removes most letterhead/table-label false positives (Giấy mời 66→77/79,
  pilot ESTABLISHES precision 0.52→0.80–1.00, SRC-089 header FPs 2→0).
- Mandatory evidence fixed the hardest navigation case (SRC-095 contents, 156→186/192) but cost
  coverage: 4/10 V2 requests failed the contract, and it regressed 4 pilot rows. Its explanations
  are partly unsupported even where the label is right.
- Abstention was never used; uncertainty is not surfaced. Remaining failure classes are contract
  shape (null-as-OTHER, fences, one omitted O#) and identifier shift.
- Small development cohort (Giấy mời is development-exposed). No generalization, end-to-end, G2/H2 or
  production claim. Downstream execution and production promotion remain LOCKED.
