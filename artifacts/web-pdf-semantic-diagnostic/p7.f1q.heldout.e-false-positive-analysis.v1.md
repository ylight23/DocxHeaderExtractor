# P7-F1Q held-out: why Qwen over-calls ESTABLISHES (analysis V1, 2026-10-11)

**Scope.** Analysis only, with no provider call and no Gold change. The input is every row that Gold labels OTHER/REPRESENTS but Qwen labelled ESTABLISHES, in the two frozen held-out arms:
- arm A: 91 false positives, ESTABLISHES precision 0.717;
- arm B: 82 false positives, ESTABLISHES precision 0.742;
- 114 distinct rows in the union of the two arms.

All false positives have Gold = OTHER. Row-level details, including Qwen's own `observedRole` and `interpretation`, are in `p7.f1q.heldout.e-false-positive-analysis.v1.json`.

**Finance (049, 051) is dominated by table rows.**
- 049 contributes 24 false positives in arm A and 34 in arm B, mostly balance-sheet and fair-value table rows on pp. 29 and 52.
- Layout-aware packing put each whole statement page into one chunk. In arm B Qwen then labelled almost every row group, and some regular-weight line items, as ESTABLISHES.

## What the raw evidence shows

1. **The evidence was in the payload, but Qwen did not use it.**
   - For 049 L0974:S0 "Market borrowings, at fair value", the request contains the same-baseline cells L0974:S1 "$", S2 "33,284 $" and S3 "26,425", with bboxes.
   - Qwen's own `observedRole` reads "Regular-weight line item label", yet its `function` is ESTABLISHES.
   - It treats "organises the content below" as establishing structure.
2. **The prompt leaves the boundary open.**
   - The only guidance is one sentence: "Do not confuse … page furniture, or local table/data labels with document headings". It is immediately followed by "A heading inside a table may still be genuine."
   - There is no operational test for a data-table row, a caption, a running header or a numbered clause that continues as body prose. The Gold policy, however, treats all of these as OTHER.
3. **The tools are almost never used.** Arm A made 4 calls and arm B 7. `get_repeated_occurrences` was never called, so running headers on the sampled pages look like one-off headings.
4. **Some disagreements are Gold-policy choices.** 14 of the 114 rows were decided or changed by the reviewer in this cycle: the 032 applicability notice, the 087 "Regarding" lines, the issuer names, the 051 fiscal-year line, and the 051 chart title. Qwen sides with the earlier draft label there. These are boundary decisions, not obvious model mistakes.

## Observable signals measured against the frozen Gold

The signals are deterministic and source-only: parser text and baselines, with no labels. They were measured on all 3,149 scored rows.

| Signal | Gold OTHER | Gold E | Gold R | False positives covered (A / B) |
|---|---:|---:|---:|---:|
| Same-baseline row with ≥ 2 numeric cells (data row) | 140 | 0 | 0 | |
| Text starts with Table/Figure/Chart/Box/Exhibit + number | 55 | 0 | 0 | |
| ≥ 50 % of the ±6 neighbouring lines are data rows (data-table region) | 175 | 0 | 0 | |
| **Any of the three** | **370** | **0** | **0** | **25 / 31** |

- A single numeric peer (TOC page numbers) also hits R rows, and a looser region threshold hits real headings such as "Contents" and "NOTE C—INVESTMENTS". The thresholds above are the ones with zero E/R hits.
- If Qwen respected these observations, ESTABLISHES precision would rise to about 0.78 (A) and 0.82 (B), with recall unchanged.
- To reach 0.90 the prompt must also state the table, caption and running-header rules. The table rows without numbers, the row groups and the HS list are not caught by numeric signals. Removing all table-row, caption and running-header false positives would give 0.908 for arm B.

## Recommended next experiment

1. **Protocol P7_F1Q_V3 prompt.**
   - Add explicit OTHER rules aligned with the Gold policy: data-table cells, row labels and row-group labels; object captions; repeated running headers/footers; cover/issuer/date/number metadata; numbered provisions whose line continues as body prose; theorem/definition lead-ins; form subject lines.
   - Replace "A heading inside a table may still be genuine" with a narrower rule: a heading that introduces a document section and happens to sit in a layout table.
2. **Payload observations, not labels:** `rowNumericCells`, `dataTableRegionFraction`, `captionPattern`, and `repeatsOnPages` (from the evidence store, so running headers are visible without a tool call).
3. **Validation on data not used here.** The held-out set has now been used for method comparison and for this analysis.
   - Run the dev pilot (small; 8 E errors in V3) as a guard.
   - Run a fresh held-out cohort, drawn with the same contamination audit from the remaining pool, with Gold reviewed and frozen before any call.
   - Pre-register the primary metric (E precision with recall non-inferiority) and a paired comparison against P7_F1Q_V2.

**Limits.** The cause groups were assigned by hand from Gold rationales and page context, and some rows could fit two groups. The signal thresholds were chosen on this held-out set, so they are hypotheses to validate, not results.
