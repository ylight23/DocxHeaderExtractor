## 1. What changed
| Area | Change | Where |
|---|---|---|
| Storage path (P0) | `Options.RequireSafeStore`: a qualification run without a safe store is refused, and a run that also names the legacy `RawDir` is refused. Every raw item is written through `P7F1V6SafeRawStore` when it is given. The legacy directory is never used silently. | `P7F1V6Hier.cs`, `P7F1V6Driver.cs` |
| Source gate (P0) | A source is allowed only if it is under `todo10_8/`, inside that corpus folder after full path resolution, a regular file (not a reparse point), and its SHA-256 equals the pinned value. | `P7F1V6Gates.cs` |
| Retention and deletion | Only directories named `run-<32 hex>` that hold nothing but `.bin` and `.tmp` files are candidates. Foreign content, reparse points and other names are never deleted. | `P7F1V6Gates.cs` |
| Route data policy (S3) | Facts are recorded with status, source URL and read date. The route gate is closed while any fact for the route is not VERIFIED. | `P7F1V6Gates.cs`, `p7.f1.v6.d3.4-data-policy-snapshot.v1.json` |
| Response adapter | Takes `choices[0].message.content` as text, unchanged. Reports `NO_CHOICES`, `NO_MESSAGE`, `CONTENT_NOT_TEXT`, `RESPONSE_NOT_JSON`. Never repairs the text. | `P7F1V6Gates.cs` |
| Provider guard | Lists every reason a provider run would be refused: no authorisation record, safe store not in use, source gate failed, data policy not verified, candidate hash not pinned, route not alibaba, retries not zero, call limit or ceiling out of range, C0 not run or not resolved. It sends nothing. | `P7F1V6Gates.cs` |
| C0 replay | `c0-pin` writes the pins for document 073. `c0-replay` refuses if the source, candidate or manifest hash differs from the pins, then runs the replay through the safe store with scripted decisions only. | `scripts/P7F1Q/C0Replay.cs` |

## 4. Open findings that block C1
1. **Document 073 may not be public.** Its file name is `073_FORTIS_GC_Minutes_Mar_2026.pdf`, in a folder named `05_bien_ban_hop` (minutes). The code cannot tell whether it is public. The corpus owner must confirm the status of this file before any transmission. Until then the answer is no.
2. **Alibaba's data policy is UNKNOWN.** The route gate is closed, so the guard refuses a provider run. Closing it needs the Alibaba Model Studio documentation read and recorded, or an approved decision to accept the risk.
3. **The retention value (30 days) and the deletion procedure are not approved.**
4. **No provider runner exists.** The guard is written; no code path sends a request after it. The adapter is written; no HTTP path calls it in a qualification run. C1 would need that path wired, tested with the mock transport, and run at a frozen commit.
5. **Symlink refusal at file level is not tested here.**

## 5. Freeze: what the pins do and do not cover
- The pins cover the source, the candidate universe and the manifest. They do not cover the code.
- The freeze branch `696d2e5` predates the D3.4 gates. A C1 run must run from a commit that contains the gates, and that commit needs its own freeze and approval. This report does not create that freeze.
