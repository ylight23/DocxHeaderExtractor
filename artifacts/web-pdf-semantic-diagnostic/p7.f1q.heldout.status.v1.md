### Reading the results

- **The primary gate is not met by either arm.** ESTABLISHES precision is 0.717 / 0.742 against a 0.90 threshold; first-attempt acceptance is 0.941 / 0.939 against 0.95. Recall passes in both arms. The dominant error is over-calling ESTABLISHES on rows Gold calls OTHER.
- **Finance is the weak stratum in both arms**, and layout chunking makes it worse there: 049 has 15 right→wrong against 5 wrong→right. The gain is concentrated in legal, procurement, textbook and translation.
- **Limits.**
  - McNemar treats each arm's single run as fixed. Run-to-run variation of Qwen with identical bodies (reasoning sampling) was not measured, so part of the 56/30 split may be noise. A replicate of arm A would measure that floor.
  - The held-out set has now been used for a method comparison. Any chunking chosen from this result must be revalidated on fresh documents.
  - This is occurrence F1 on sampled pages. Parser coverage gaps (028 p229, 056 cover, 083 L1075, 087 L1216) are outside it.
