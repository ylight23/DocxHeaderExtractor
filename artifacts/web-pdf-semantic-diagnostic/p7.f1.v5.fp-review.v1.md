## Diagnosis
1. **Prompt regression, most likely cause.** The V4.1 prompt lists explicitly the competing explanations: table labels, table and figure captions, numbered legal provisions, front matter (issuer, document number, date, reporting period), form fields and administrative blocks, and running headers. V5 keeps the question short and dropped that list when the region reasoning was added. Almost every false positive above is in one of these classes. The region statements are often correct (for example "Table D2 caption", "Financial statement table"), so the model describes the region well and still selects a line that its own statement says is not a heading. This is an inconsistency between reasoning and selection, not a missing-evidence problem.
2. **094 table of contents:** fixed (25 false positives in V4.1, 6 in V5). The remaining 094 errors are an intro sentence and a document number, not table of contents lines.
3. **Definition conflict (087):** the task wording and the Gold policy disagree about form identifiers. This needs a decision on the definition, not a change of Gold.

## What this does not show
- It does not show that region reasoning is worse. It shows that V5, as written, lost the specific guidance that V4.1 used, so the two arms differ in more than the reasoning unit.
- A controlled test would be a V5 run with the V4.1 competing-explanations list restored. That is a new protocol and needs a new plan and a new authorization. It was not run.

## Recommendation
- Keep V4.1 as the best measured configuration.
- If V5 is continued, restore the V4.1 competing-explanations list in the V5 prompt first, and treat that as a new protocol version.
- Decide the form-identifier definition (Form No. 02/05) before any further Gold or prompt work. Do not adjust Gold to raise the score.
