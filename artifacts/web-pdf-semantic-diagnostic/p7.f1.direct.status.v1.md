### Source enrichment

- **Input.** It reads the unchanged `P7_RAW_SOURCE_EVIDENCE_STORE_V1` through `P7F1QEvidenceTools` and the parser layout blocks.
- **Observations per line:**
  - same-baseline row peers, and how many are numeric;
  - neighbouring rows with two or more numeric cells;
  - the nearest caption-pattern candidate: above on the same page, the line itself, or on the previous page (UNRESOLVED);
  - the previous page's last rows, with continuity always UNRESOLVED;
  - the number of pages with the same normalised text;
  - the trailing page number and dot leaders, the same text elsewhere, and a candidate-only target;
  - vertical position and layout block.
- **Statuses.** Every relation carries SUPPORTED_BY_LAYOUT, SUPPORTED_BY_PARSER, UNRESOLVED or NOT_AVAILABLE.
- **What it never asserts:** table membership, caption ownership, cross-page continuity or a navigation target. It applies no filter and no label.
- **Wire form.** A compact form plus a legend sent once per request. Issued lines get the full record; context lines get `{num, data, rep, cap}`.

### Direct protocol

- **Question.** One per request: does each issued occurrence contribute to a genuine document heading at its own location? The prompt lists the competing explanations (table / statement labels, captions, list / clause / theorem lead-ins, navigation entries, form parts, front matter, running headers), and says that a heading inside a table may still be genuine.
- **Answer.** Sparse: `headings[]` (occurrence, sourceAlias, evidenceRefs, justification) plus `unresolved[]`. There is no E/R/O, kind or hierarchy in the contract.
- **Scope.** Signed by `requestId` and `issuedSetSha256`.
- **Validator.** Strict, fail-closed, on a non-frozen runner hook (`ControlValidator`). Tools and runner are reused unchanged.

### Exact binder

- **Checks.** It re-validates frozen raw against the signed scope: plan scope hash, source identity (page and text), O# ↔ alias, and duplicates. Every tool evidenceId must exist in the raw tool transcript and cover the subject.
- **Binding.** Every selection is bound to parser text, page and bbox, including semantically wrong ones.
- **Statuses:** ACCEPTED_COMPLETE, INCOMPLETE, CONTRACT_FAILED, TRANSPORT_FAILED, BUDGET_STOP, MISSING. Negatives come only from omission in an ACCEPTED_COMPLETE response.

### Independent evaluator

- **Isolation.** It has no project references and reads only SHA-pinned frozen inputs.
- **Universe and labels.** Universe = adjudicated Gold rows. Positive = Gold E. Unresolved and missing rows count as FN in recall; coverage and abstention are reported separately.
- **Old-protocol conversion.** The F1Q V2 control conversion (E → POS, R/O → NEG) exists only here.
- **Statistics.** Wilson intervals, per document, per page stratum, and a paired comparison: row McNemar, document sign test, and a document-cluster bootstrap (10,000 resamples, seed 20261011).

### Execution

- `prepare-direct` freezes the plan and bodies.
- `execute-direct` refuses to run without `P7_F1_DIRECT_PROVIDER_AUTHORIZATION_V1` signed by the user, pinned to the plan sha, with its own USD cap. Endpoint metadata names include the process id, which fixes the earlier start-up collision.
- `bind-direct` binds frozen raw with the manifest pinned; it reads no Gold.

**Tests.** `P7F1DirectHeadingTests`, 29 tests:

- foreign id, foreign alias, wrong scope or request;

### Recommended V4.1 before any fresh-cohort run (revised after the external audit; needs the user's decision)

**What the audit corrected.**
- The V4 prompt already lists table-of-contents and list entries as competing explanations, and Qwen still selected them. A further TOC sentence is therefore **not** evidence of a fix.
- Even with all 6 failed requests recovered, recall would only reach 0.898 (17 headings back, the 25 omissions unchanged). Fixing the contract alone cannot pass the 0.90 recall gate.

**V4.1 changes:**
1. **Contract only, no change to the semantic task.**
   - One opaque id per issued occurrence; C# resolves the sourceAlias.
   - No model-echoed SHA-256 (scope is checked server side).
   - An absent `unresolved` is read as empty under the new frozen contract.
   - V4 raw is never edited.
2. **At-location condition, still direct membership.** Select an occurrence only if it opens a content region **at that location**. A line that names a heading which operates elsewhere (contents, list of tables, index) is not selected because of that wording. There is no return to E/R/O and no C# mapping.
3. **Report both views.** End-to-end F1 is the gate. Accepted-only diagnostic F1 shows semantic quality separately from contract loss and never replaces the gate.
4. **Decision–evidence consistency audit.** An independent report lists selections whose own justification contradicts the claim (e.g. "in the table of contents"). It is audit only; C# never deletes a selection.
5. **Order.** Run the 24-document regression first. It must show that the TOC false-positive family (067/094), the finance-table family (049) and the omitted true headings (009/015 "LUẬT", 024 "Mục", 028 revision dates, 034 "Form CCC", 044 "Figures") all shrink. Only then: fresh-cohort Gold approval and freeze, then a separate provider authorization.

The V4 pilot raw and the V4 scores stay frozen as the comparison baseline. The V4 pilot does not justify running V4 on the fresh cohort.
