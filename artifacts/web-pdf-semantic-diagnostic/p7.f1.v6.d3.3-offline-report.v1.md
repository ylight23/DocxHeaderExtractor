# V6 D3.3: offline report (Issue #9): raw storage, data policy, transport, inventory

Written for: the Issue #9 reviewers, to decide whether D3.3 is accepted as an offline baseline.
Status: OFFLINE ONLY. No API call, no metadata GET, no inference, no freeze, no Gold or production change.
Baseline: commit 10a2b3d (D3.2a). Model `qwen/qwen3.7-flash`. Route policy: only `alibaba`, ignore `alibaba/us-east-1`, no fallback.

## 1. What changed
| Area | Change | Where |
|---|---|---|
| Inventory (P0) | `EvaluateRoute` takes full endpoint rows (tag, model id, context, max completion). Eligible only if: inventory non-empty; every tag approved; every row has the expected model and metadata; after the route policy exactly one endpoint remains, tagged `alibaba`. Reasons are named. | `P7F1V6Protocol.cs` |
| Raw storage (S1) | `P7F1V6SafeRawStore`: one fresh run directory per run; items written to a temp file with WriteThrough, flushed, moved into place with no-overwrite, then read back and hashed; names validated as 64 lowercase hex; reparse points refused; on Windows the run directory keeps one access rule, for the current user, with inheritance removed; `VerifyOnDisk` re-hashes every file. | `P7F1V6SafeStore.cs` |
| Data policy (S2) | Allowed sources: the `todo10_8/` corpus prefix only; path traversal refused; redaction never replaces the original identity (`REDACTED_COPY:…:OF:…`); retention 30 days is a proposal. | `P7F1V6SafeStore.cs` |
| Transport (T1–T3) | `P7F1V6OpenRouterTransport` sends the `PreparedRequest` bytes only; the bytes that pass into the HTTP content stream are captured and hashed at the boundary; redirects are refused; no retry; one timeout; the key is put only into the Authorization header and never returned. | `P7F1V6Transport.cs` |
| Model boundary (T1) | Every model call receives the `PreparedRequest` itself (`PreparedNodeModel`). Node and interpretation calls use the same prepared body that was measured, checked, stored and recorded. The old `NodeModel` overload remains for existing tests. | `P7F1V6Hier.cs` |
| Usage audit (T3) | Unchanged logic; now also run on transport responses in tests. | `P7F1V6Usage.cs` |

## 2. Acceptance by item
### S1 — raw storage
| Requirement | Status | Evidence |
|---|---|---|
| Directory per run | DONE | `CreateRun` makes `run-<GUID>`; two runs get different directories |
| Only the run owner can access it | DONE on Windows (test reads the access rules: exactly one, current user, Allow). NOT ENFORCED on other systems; the operator must set it there |
| Atomic creation | DONE | temp file, FileMode.CreateNew, WriteThrough, Flush(true), File.Move with overwrite false |
| No following of symbolic links out of the root | PARTIAL | reparse points on the root, the run directory and each file are refused. No test creates a real symlink (not possible reliably here); the check is in code only |
| Hash verified from disk | DONE | `Put` and `ReadVerified` read the file back; `VerifyOnDisk` lists altered items |

### T1–T2 — transport
| Requirement | Status | Evidence |
|---|---|---|
| Sends the prepared bytes, not an adapter's own serialization | DONE | `Send` takes `PreparedRequest`; the mock handler receives bytes equal to the prepared body |
| Hash checked at the HTTP boundary | DONE | `BoundaryContent` captures the bytes written to the stream; `BOUNDARY_SHA_MISMATCH` otherwise. A prepared body with a wrong hash is refused before any send (`PREPARED_SHA_MISMATCH`) |
| No redirects | DONE | production handler `AllowAutoRedirect = false`; a 3xx reply is `REDIRECT_REFUSED` |
| No automatic retry | DONE | one attempt per send; tests count handler calls |
| Timeout and cancellation | DONE for the mock (`TIMEOUT_OR_CANCELLED`); a real network timeout is not tested |
| Authorization never in raw or transcript | DONE | the result has no header field; tests check the key is absent from the result |
