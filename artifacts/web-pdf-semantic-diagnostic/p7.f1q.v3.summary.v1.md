## What changed (audit item → change)

| Audit finding | V3 change |
|---|---|
| Qwen lacked the layout to judge subtitles, letterheads, contents | Initial payload carries parser layout for every issued and context line (bbox, font size, bold/italic ratio) plus per-page text extent and median font size. Observations only, no labels or Gold. |
| Prompt asked for evidence but not for competing interpretations | Protocol `P7_F1Q_V2` adds the evidence-grounded judgment steps (own-occurrence claim, competing functions, subtitle vs body prose without a proximity rule, TOC location comparison, `INSUFFICIENT_EVIDENCE` not `OTHER`, no unsupported layout claims). |
| A valid alias was accepted as proof; identifier shift went unnoticed | Each decision repeats its `sourceAlias`; the validator rejects `SOURCE_ALIAS_MISMATCH` and `EVIDENCE_NOT_ABOUT_SUBJECT` (no ref to the subject itself or to a tool result that covers it). |
| Context tool returned text only; no TOC ↔ heading comparison | Tool set V2: `get_occurrence_context` returns layout, spatial relations (same baseline, vertical offset, overlap, font delta) and row peers; new `compare_occurrences`. |
| Explanations could contradict the PDF | Deterministic layout-claim audit (`P7F1QClaimAudit`, heuristic English keywords) checks position, bold, uppercase, header/footer and column claims against the decision's own observations; contradictions are reported separately. |
| JSON fences, 95/96 cardinality | `response_format: json_object` on every turn; packs split into ≤48-occurrence chunks keeping the original O# ids. |
| Retry | At most one identical-body retry per request, on transport or contract failure, never on semantics; no repair; no in-turn retry. |

Not done in V3: page images / Vision (P2, separate multimodal arm), semantic verification of interpretation text
beyond layout claims.

## Verdict

- The audit-driven fixes give the first F1Q run with full strict coverage after one retry (20/20, 501/501 rows) and the
  best scores so far on both Gold sets:
  - pilot 206/213, ESTABLISHES precision 0.82 / recall 0.90;
  - SRC-089/095 287/288, ESTABLISHES precision 0.96 / recall 1.00;
  - layout contradictions 1 vs 36 in V2.
- The identity check caught a real identifier shift (rejected, then retried clean).
- Still open:
  - abstention is never used;
  - subtitle vs body prose (O6/O7) is unresolved;
  - clause/data-sheet rows are over-called as headings;
  - interpretation text is verified only for layout claims;
  - json_object does not prevent fences on this endpoint.
- Small development cohort (Giấy mời is development-exposed). V3 relies on the retry for 3/20 requests; first-attempt
  results are reported separately. No generalization, G2/H2, end-to-end or production claim; downstream execution and
  production promotion remain LOCKED.
