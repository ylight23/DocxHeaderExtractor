### Driver (`P7F1V6Driver`): interpret → packs → reconcile → finalise, with a deterministic transcript
- Each step writes an event (payload SHA-256, tool call, tool result with content SHA-256, final SHA-256, pass status). The transcript SHA-256 is recomputed in the test and is stable across two runs (`The_transcript_is_deterministic...`).
- Paths covered by tests: full RESOLVED run; no tool call; several tool rounds citing a recorded evidence id; CLARIFICATION_REQUIRED stops the run; an unparseable interpretation fails the run; a tool outside the list is refused (not executed); a page outside the granted scope is denied and recorded; more tool rounds than the limit fail the pass; a heading split across two packs is decided by the reconcile.
- **Full document:** `A_full_document_run_covers_every_placed_line_of_the_real_RFC_document` runs the real RFC 094 with one pack per page and one reconcile. Every placed line receives an explicit final state, and the run reaches RESOLVED with no violation.

### Requirement 1: one PDF, two requests, no C# change (scripted evidence only)
`Two_different_requests_on_the_same_PDF_give_different_resolved_results_with_the_same_contract_and_prompt`: the same source universe, the same fixed system prompt (`SystemPromptSha256`), the same packs and the same code path. The two instructions give different transcripts (different SHA-256) and different selected counts, and both reach RESOLVED.

### Requirement 4: injection and adversarial criteria (D0.v2 section 6)
- (a) and (b): `Criteria_a_and_b_...`. An injected tool call is refused and not executed. The run continues on the real task, and the instruction is unchanged.
- (c): `Criterion_c_...`. A page outside the granted scope is denied and recorded.
- (d): `Criterion_d_...`. A line with injected text (`IGNORE PREVIOUS INSTRUCTIONS…`) is added to page 2. An honest model's decisions on every original packed line are unchanged. A model that obeys the injected text changes only that line.
