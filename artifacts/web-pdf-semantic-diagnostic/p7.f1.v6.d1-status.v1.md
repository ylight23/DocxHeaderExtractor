## Update: contracts fixed and read tools built (commit 8eb3731; P7 suite 642/642)

### P0 fixes (from the review of 1bdfce9)
1. **Evidence ids are proven, not pattern-matched.** `ParseDecisions` takes the transcript. A tool id is accepted only when the transcript holds a record for it with the same request and source, status OK, and a returned alias equal to the decided subject. Tests: `A_tool_evidence_id_is_accepted_only_when_the_transcript_proves_it` (not issued; wrong request or source; status ERROR; result without the subject's alias; accepted case).
2. **Status is split, not merged.** `P7F1V6Core.Status` returns `CoverageComplete` (no MISSING), `ResolvedComplete` (only SELECTED or NOT_SELECTED), `Selected`/`NotSelected`/`Unresolved`/`Missing` counts, and an `Assessment` (INCOMPLETE, PARTIAL_UNRESOLVED, RESOLVED). `DocumentComplete` is removed. Test: `A_later_reconcile_pass...` asserts CoverageComplete true, ResolvedComplete false with one UNRESOLVED.
3. **Observed versus evaluated scope.** `P7F1V6Core.Scope` reports observed, evaluated, observed-but-not-evaluated and evaluated-but-not-observed. Test: `Observed_and_evaluated_scopes_are_reported_apart...`.

### Read tools (new, `P7_F1_V6_READ_TOOLS_V1`; V2–V5 tools unchanged)
- `search_document_text`: literal or normalised (diacritics folded, đ folded, case and all whitespace removed) over granted pages, in source order. Paginated with `totalMatches`, `offset`, `limit` (1–50), `returned`, `hasMore`, `nextOffset`. Reports `unplacedLinesExcluded` and `sourceStatus`.
- `get_page_text`: every line of one page in reading order, with alias, page, ordinal, text, and the parser's bbox and font. Paginated the same way.
- Errors with explicit codes: QUERY_EMPTY, QUERY_TOO_LONG, MODE_INVALID, OFFSET_INVALID, LIMIT_INVALID, PAGE_NOT_IN_DOCUMENT, SCOPE_DENIED.
- Provenance on every call, including errors: sourceSha256, universeSha256, storeSha256, evidenceId, contentSha256 (recomputed by the test), returned aliases, tool version.
- Two scope ledgers, both snapshots: `observedAliases` (returned to the model) and `searchedAliases` (returned by search).
