# Pairwise PDF heading boundaries with source facts

Prior candidates and all failures remain frozen. Grouping has sufficient syntax checks but accepts
semantically wrong whole-run merges. Rich selection facts are dropped at the grouping handoff.
The removed semantic verifier must not be reinstated as production authority.

This candidate changes the grouping answer contract to an explicit JOIN/SPLIT decision at every
adjacent selected pair, with exact alias/selectedText echoes and a brief boundary justification.
It includes existing measured layout/style/block facts, the document style table, and up to three
nearby source lines on each side. Facts never label a boundary. C# validates every pair and folds
the model decisions into groups; the established coverage/order/size checks remain. There is no
semantic C# veto, keyword split, second reviewer or extra stage. Source extents and membership stay
fixed, cache/request identities include the new payload/prompt, and optional PDF flags default false.

Run focused protocol/integration tests and broad regression without a concurrent build. Freeze src,
tools and test C# identity before provider calls. Existing source and registered Gold are unchanged.
Gold is used only by scorers, never provided to the model.

Controlled grouping: two predeclared repetitions each of the same frozen failed full PDF072 V5
selection (full-02, 45 selected aliases, 44 correct plus one extra) and completed V5 PDF076 first-scope
selection (five selected aliases, four expected groups). Require complete exact selected coverage,
no failures/fallback, no missing Gold aliases; PDF072 >=41/42 exact groups, PDF076 all four exact groups,
including its real two-line title. Count both repetitions. Stop progression if a conjunctive gate
fails; do not repeat an unchanged failed revision until favorable. Explicitly record unrun trials.

If all four pass, run two full PDF072 samples using V5 membership, source binding, separate grouping
instruction, pairwise grouping and parent-chain repair, without optional membership review or inline
grouping. Require every Gold alias, at most three extras, >=41/42 exact groups, 15 complete scopes
owning all 650 aliases once, no unresolved membership, grouping fallback, placement failure or residual
parent conflicts, <=5 unresolved parents, each <300 seconds. Both samples count.

Before any general default promotion, also run independent full PDF076: require all registered Gold
aliases and exact heading groups, no extras, complete source scope/alias coverage, no grouping fallback,
unknown membership, placement failure or residual chain conflict, <=5 unresolved parents, <300 seconds.
No Gold hierarchy correctness claim is possible. A failed full gate is preserved and prevents promotion.
These bounded experiments do not establish a universal accuracy or five-minute latency SLA.
