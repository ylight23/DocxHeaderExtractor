  - 1.4 Probability Spaces A probability space is defined by (Ω, F, P) where Ω is the sample space or the space of all possible outcomes, F is a sigma-algebra and P is a probability measure. The sigma-algebra F contains the sets (sometimes called events) that can be measured. For- mally, F ⊆ 2Ω where 2Ω is the power set of Ω is called a sigma-algebra if the following three properties hold: (1) B ∈ F implies Ω \ B ∈ F, i.e., it is closed under complements. (2) Ω ∈ F. (3) If B1 , B2 . . . is a countable collection of sets in F then ∪i Bi ∈ F, i.e., it is closed under countable unions. The probability measure P is a function that assigns to any set in F a number between 0 and 1, and satisfies (1) P(Ω) = 1, P(∅) = 0. (2) If B1 , B2 . . . is a countable collection of pairwise disjoint P sets in F, i.e., Bi ∩ Bj = ∅ for all i, j, then P(∪i Bi ) = i P(Bi ). For the rest of these lectures, Ω will be endowed with a metric d and (Ω, d) will be a separable metric space. Let B be a collection of subsets of Ω. The smallest sigma-algebra containing all the sets of B is called the sigma-algebra that is generated by B. For any collection of sets B the sigma-algebra that is generated by B exists (see exercises) and is denoted by σ(B). We are now ready to define the Borel sigma-algebra. Definition 1.2 Let (Ω, d) be a metric space. The Borel sigma-algebra on Ω is the sigma-algebra that is generated by all the open sets of Ω. A set is called a Borel measurable set if it belongs to the Borel sigma-algebra. A function f : Ω → R is called a Borel measurable function if f −1 (V ) := {ω ∈ Ω : f (ω) ∈ V } is a Borel measurable set in Ω for every open set V in R. Remark 1.1 When Ω is countable then we will assume it is endowed with the discrete distance, i.e., d(x, y) = 1 if x ̸= y and d(x, x) = 0. In this case every set is open (why?), and hence, the Borel sigma-algebra is 2Ω and every function is Borel measurable. This complexity makes it impossible to compute and store the value function for every possible state, due to both computational constraints. The computational burden of solving the Bellman equation increases significantly with the size of the state space, making traditional methods like value function iteration impractical. This phenomenon is called “the curse of dimensionality”. In addition, in many applications the payoff and transition functions may be unknown. We will discuss some basic ideas to overcome these issues in this Lecture. In Section 4.1 we will present a state aggregation method to overcome large state spaces. In Sections 4.2 and 4.3 we will cover material from probability theory and optimization such as conditional expectations, and stochastic gradient descent algorithms that are needed to analyze the Q-learning algorithm. Each cluster is treated as a single state in the aggregated model, significantly reducing the size of the state space. The value function is then defined over these aggregated states rather than individual states. This reduces the number of calculations and the amount of memory required to implement dynamic programming algorithms. Hence, aggregation decreases the number of states and makes it possible to solve large dynamic programming problems. However, it can have some serious limitations depending on the specific dynamic optimization problem. Sometimes state are too different and aggregation can lead to highly sub-optimal policies. 53  <!-- lvl=1 i=107 sid=body[1]/p[108] src=Structure CẦN-XEM-LẠI -->
    - 4.2.2 Filtration A filtration is a sequence of sigma-algebras that represent the accumulation of information over time. Formally, a filtration {Fn }n≥0 is a collection of sigma-algebras such that: F0 ⊆ F1 ⊆ F2 ⊆ · · · ⊆ F. Each Fn represents the information available up to time n. A filtration can be defined by random variables as the sigma-algebra generated from them. For a sequence of random variables {Xn }n≥0 , the natural filtration {Fn } is given by: Fn = σ(X0 , X1 , . . . , Xn ), which is the smallest sigma-algebra with respect to which X0 , X1 , . . . , Xn are measurable. We say that the sequence {Xn }n≥0 is measurable with respect to a filtration {Fn } if Xn is Fn -measurable for each n. For example, Suppose that Xn are Bernoulli coin flips, where Xn = 1 if the coin flip results in heads (with some probability p), and Xn = 0 if it results in tails and define Fn = σ(X0 , X1 , . . . , Xn ). Then F0 is generated by X0 and contains all possible information outcomes of the first coin flip. It consists of the sets {∅, Ω, {X0 = 0}, {X0 = 1}}, where Ω is the sample space of all possible outcomes. Fn includes information from all Xk for k ≤ n. For example, a random variable Yn = X0 + X1 + . . . + Xn (the total number of heads up to time n) is measurable with respect to Fn , as it is a function of the outcomes X0 , . . . , Xn but is not measurable with respect to Fn−1 . 4.2.3 Martingales, Sub-Martingales, and Super-Martingales Martingales are a powerful tool in probability theory due to their convergence properties and wide range of applications.
