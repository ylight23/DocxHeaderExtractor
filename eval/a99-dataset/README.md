# A99 reference authority and family freeze

The freeze artifacts are generated by `scripts/a99-dataset-freeze.ps1`. The generator is deterministic, offline, and provider-free. It inventories committed document sources, hashes exact bytes, assigns conservative authority labels, groups exact duplicates, and emits coarse evaluation metadata.

Path-based family assignments are intentionally conservative and must be reviewed before using the data for an accuracy claim. `trueBlindAvailable` is false because committed references are visible in this repository. No production extraction file is changed by this lane.
